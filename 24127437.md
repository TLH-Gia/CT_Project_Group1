## I. Objective  
Design and implement an **AI-powered recommendation pipeline** for intelligent food and restaurant suggestions.  
The system should understand user inputs (text or image), extract meaningful information, and provide tailored restaurant or dish recommendations based on location, taste preferences, dietary restrictions, and budget.

### Main Goals:
- Analyze natural language from user input (text or image).  
- Link extracted information with location-based restaurant data.  
- Rank and return the top 3–5 most relevant suggestions.  
- Ensure fast response time (< 2s) and high accuracy (QFR ≥ 80%).

---

## II. Sub-problem Analysis

| Component | Description | Expected Output |
|------------|--------------|------------------|
| **1. Input Processing** | Receive user data (text, image, or geolocation). Normalize and clean input, support both English and Vietnamese. | Clean text ready for NLP processing. |
| **2. NLP Intent Recognition** | Use Gemini API to identify **user intent** and **entities** such as dish, area, diet, flavor, or price. | JSON object containing `{intent, dish, area, diet, price, flavor}` |
| **3. Data Query & Matching** | Query **Google Places API** using extracted entities to fetch relevant restaurant data. | Raw list of 10–15 candidate restaurants. |
| **4. Ranking & Recommendation** | Apply ranking criteria (distance, rating, flavor match, price) to compute a **Recommendation Score** for each candidate. | Top 3–5 restaurants with scores. |
| **5. Response Generation** | Format and return the final results including name, address, dish, price level, rating, and map link. | JSON or HTML-formatted cards for UI display. |
| **6. UX Feedback Collection** | Collect user feedback (clicks, acceptance rate) to evaluate system performance and model consistency. | Logs for SAR, MA, and performance analysis. |

## III. Proposed Technologies

| Component | Tool / Library | Notes |

## V. Technology Comparison

| **Criteria**               | **Gemini API**             | **ChatGPT API**            | **Hugging Face**           |
|-----------------------------|-----------------------------|-----------------------------|-----------------------------|
| **Intent & Entity Accuracy** | High                        | Very High                  | Medium                     |
| **Integration Ease**        | Easy (Google ecosystem)     | Moderate                   | Easy                       |
| **Latency**                 | Low                         | Moderate                   | Low                        |
| **Cost**                    | Free (educational use)      | Paid                       | Free                       |
| **Project Suitability**     | Best balance             | Overkill               | Limited NLP capability  |

**Conclusion:**  
The combination of **Gemini API + Google Places API** offers the best performance-to-complexity ratio, with fast responses, easy integration, and sufficient NLP power for project requirements.
