# User Feedback & Rating System  
**Branch:** `test_users_feedback_analytics`  
**Author:** Nguyen Ngoc Gia Bao  
**Technology Stack:** Flask, SQLite, Chart.js, HTML

---

## I. Objective  
To design a **feedback and rating system** that collects user input to measure satisfaction, usability, and visual appeal of the current web app.  

### Core Requirements:
- Collect **rating (0–5)** and **text-based feedback** through an HTML form.  
- Store feedback securely in an **SQLite** database.  
- Display **statistical results** such as average rating, feedback count, and sentiment summary.  
- Visualize results dynamically using **Chart.js** on the analytics page.  
- Maintain **user anonymity** (no personal data stored).  

---

## II. Functional Breakdown  

| Component | Description | Technology | Example Output |
|------------|--------------|-------------|----------------|
| **Feedback Form (HTML)** | UI for users to rate and comment | HTML5 + CSS3 |  “Great app, easy to use!” |
| **Flask Backend (Python)** | Handles POST requests and database insertion | Flask routes | `@app.route('/feedback', methods=['POST'])` |
| **SQLite Database** | Stores ratings and comments persistently | SQLite | `feedback.db` |
| **Data Analysis Script** | Calculates mean rating and sentiment trend | Python (pandas) | “Average rating: 4.3/5” |
| **Chart Display (Chart.js)** | Visualizes trends and distribution | JavaScript (Chart.js) | Pie, Bar, or Line charts |

---

## III. Feedback & Testing Flow  

1. **User submits** rating and comment.  
2. **Flask backend** validates and stores input into `feedback.db`.  
3. **Data analytics module** computes:  
   - Average score  
   - Total number of responses  
   - Keyword sentiment (optional)  
4. **Chart.js** dynamically loads data and visualizes trends.  
5. Results appear on `/test_feedback` page for analysis.  

---

## IV. Comparison of Technology Choices  

| Feature | **Flask + SQLite + Chart.js** | **Django + PostgreSQL** | **Node.js + MongoDB** |
|----------|-------------------------------|--------------------------|------------------------|
| **Complexity** | Lightweight & beginner-friendly | High (full MVC structure) | Moderate |
| **Performance** | Fast for small-scale projects | Excellent for large-scale | Scalable with load balancing |
| **Setup Time** | Very short | Long | Moderate |
| **Visualization** | Uses Chart.js easily | Requires third-party JS libs | Uses Chart.js or D3.js |
| **Best For** | Educational or prototype systems | Enterprise apps | Real-time web apps |

 **Chosen Stack:** Flask + SQLite + Chart.js  
→ Simple, fast to deploy, and perfect for testing feedback features.
