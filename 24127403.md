---

## 1. Problem Definition

In a vibrant city like Ho Chi Minh City, there are thousands of food options — from local street dishes to international restaurants.  
However, both locals and visitors often struggle to **discover new, delicious dishes or hidden food spots** efficiently.  

The goal is to **design a clean, user-friendly, and visually appealing web interface** that allows users to:
- Explore recommended dishes based on categories or location.
- View details and images of each dish.
- Switch between **light and dark mode** for better user experience.
- Interact easily on desktop.

---

## 2. Decomposition

To ensure an organized workflow, the interface design process is divided into several components:

| Component | Description |
|------------|--------------|
| **Homepage Layout** | Create the main structure (header, navigation, search bar, content grid, footer). |
| **Food Card Component** | Display food name, image, description, and rating in a card format. |
| **Theme Toggle (Light/Dark Mode)** | Add a switch button to change between themes using JavaScript. |
| **Responsive Design** | Ensure proper display on different screen sizes (desktop, tablet, mobile). |
| **Static Assets Integration** | Add placeholder images and icons for testing visual elements. |
| **Style System** | Define color palette, typography, and spacing for UI consistency. |
